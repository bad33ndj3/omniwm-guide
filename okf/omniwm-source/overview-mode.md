Displays all workspace windows as a scrollable thumbnail gallery. Activate: `Option + Shift + O`.

# Discovery/selection
Type to filter windows live; `Backspace` removes search text. Arrow keys = spatial navigation; `Tab`/`Shift+Tab` cycle matches. `Enter` or click focuses selection.

# Window management inside Overview
- `Command + W` closes windows, keeps Overview open
- `Option + drag` moves thumbnails to workspaces/positions
- Standard move/reorder/transfer shortcuts still work inside Overview

# Visual
Settings adjust baseline zoom, backdrop/border colors. Temporary zoom: `Alt + Shift + Mouse Scroll`.

Thumbnails require optional Screen Recording permission; without it, Overview still works, cards render without window pictures. Empty workspaces auto-hidden; selected thumbnails auto-scroll into view during keyboard nav.

A true quake/sticky terminal summoned over any workspace. Real embedded terminal built on Ghostty's libghostty (not a wrapper) — supports multiple tabs and splits within tabs.

Toggle: `Option + \`` (backtick) by default, customizable in Settings > Hotkeys.

# Position & size (Settings → Quake Terminal)
- Position: Top, Bottom, Left, Right, or Center (default). Edges slide in; Center fades in place.
- Monitor: Mouse Cursor's Monitor, Focused Window's Monitor (default), or Main Monitor
- Width/height: 10-100% of screen in 5% increments, both default 50%
- Manual resize by dragging edges; move by holding `Option` while dragging. Per-monitor saved settings, reset option available.

# Appearance
Background Effect: Standard Blur (adjustable radius), Regular Glass, or Clear Glass. Opacity 10-100%.

# Behavior
Animation Duration 0-1s (default 0.2s). Optional Auto-hide on Focus Loss.

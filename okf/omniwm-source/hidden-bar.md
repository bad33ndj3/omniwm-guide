Conceals selected menu-bar icons, lets you reach them from a panel.

- Select which apps to hide: Settings → Hidden Bar
- Right-click or Option-click the OmniWM menu bar icon → opens the Hidden Icons Bar panel
- Click any icon in the panel to temporarily reveal/use it
- Hidden icons re-hide after a configurable interval (default 5s)
- Optional global hotkey, starts unassigned

Requires macOS 27+; rest of OmniWM supports macOS 26+.

Status bar menu has a "Hide Menu Icons" toggle tile (shown only where concealment is available).
